## AI にインストールを頼む

研究に使っているエージェントへ、この指示を貼り付けてください。

```text
現在の環境に PaperSpine をインストールしてください。まず公式ガイドを読んでください。
https://wubing2023.github.io/PaperSpine/v6/llms.txt

作業と環境に合う版を選び、ZIP を SHA-256 で検証してください。インストール後、バージョンを確認して Skill の呼び出し方を教えてください。
```

[エージェント向けのインストール手順](https://wubing2023.github.io/PaperSpine/v6/llms.txt) · [リリースマニフェスト（JSON）](https://wubing2023.github.io/PaperSpine/v6/channel.json)

## 三つの使い方

<a id="start-with-skill"></a>

### クイックスタート · 全工程 Skill

エージェントとのチャットで、研究課題、データ、または草稿を渡して `$paper-spine` を呼び出します。合意した範囲に沿って研究ノート、分析、図、編集可能な論文を受け取れます。

[**ZIP をダウンロード**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-skill-6.0.0-beta.2.zip) · ![GitHub Release ダウンロード数](https://wubing2023.github.io/PaperSpine/v6/downloads-skill.svg?style=flat)

### 工程ごとに使う · Skills パック

全工程は `$paper-spine` で実行できます。個別の工程も呼び出せます。例えば `$paper-spine-followwriting` は、自分の結果と参考論文を用いた節の改稿に使えます。

[**ZIP をダウンロード**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-skills-pack-6.0.0-beta.2.zip) · ![GitHub Release ダウンロード数](https://wubing2023.github.io/PaperSpine/v6/downloads-skills-pack.svg?style=flat)

### ローカル作業画面 · Web プラグイン

オプションのローカル作業画面を追加すると、ブラウザーで図や草稿を確認し、改稿コメントを送れます。Skills パックを含み、Windows x64 の Codex で `$paper-spine-web:paper-spine-web` を呼び出します。

[**ZIP をダウンロード**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-web-plugin-6.0.0-beta.2-windows-x64.zip) · ![GitHub Release ダウンロード数](https://wubing2023.github.io/PaperSpine/v6/downloads-web-plugin.svg?style=flat)

<details>
<summary><strong>五つの段階 Skill とプロンプト例</strong></summary>

| Skill | 依頼の例 |
| --- | --- |

| `$paper-spine-deliver` | 編集可能な論文、閲覧用の写し、裏付け資料をエクスポートしてください。 |

<a id="installation"></a>

## インストールと更新

ZIP を公開チェックサムと照合してから展開します。展開先で管理ツールを実行し、元の ZIP のパスと完全な SHA-256 を渡します。その後、ホストで新しいチャットを開きます。

```text
python -B edition_manager.py install "<original ZIP path>" --sha256 <SHA256>
```

管理ツールには Python 3.12 以上が必要です。Web 版には Windows 用 Python が同梱され、Codex CLI も必要です。管理ツールでのインストールは更新の自動確認、手動更新、ロールバック、アンインストールに対応します。草稿とローカル作業は保持されます。

[インストール、更新、アンインストール](https://wubing2023.github.io/PaperSpine/v6/ja/install.html) · [SHA-256 チェックサム](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/checksums.sha256) · [V6 リリース](https://github.com/WUBING2023/PaperSpine/releases/tag/v6.0.0-beta.2)

## PaperSpine が研究の根拠を論文に組み込む方法

- **出発点に合わせて作業範囲を決めます。** 研究課題から始める場合は公開データの収集や新しい分析が必要なことがあります。結果がある場合は、必要な図、論証、レビューへ直接進めます。各工程のファイルと判断はエージェントが引き継ぎます。
- **文章の判断と科学的根拠を別々に追跡します。** Followwriting は構成や表現の参考にした箇所を示します。主張は自分の研究の根拠で支えます。分析のソース、図の元データ、引用は検証できるように残します。
- **同じ論文の中でレビューします。** 選択した図と指摘を編集可能な論文とともに保存します。改稿では根拠に立ち戻り、影響を受けた文章や図を更新して変更の記録を残せます。

LIGO の研究がその実例です。論文の到達順が、位置合わせしたひずみと九つの前処理検証にどう対応するか確認できます。[LIGO の根拠とソース](https://wubing2023.github.io/PaperSpine/v6/ja/#gravitational-waves)

## 同等の初期条件で比べた大西洋の熱帯低気圧の強化

単体 Skill で NOAA のベストトラックデータを 42 シーズン比較しました。同等の初期条件にある 6,017 の 24 時間区間では、30 ノットしきい値で +0.81 ポイント（シーズン単位のブートストラップによる 95% 区間 −1.69〜+3.43）。25 ノットでは点推定の符号が反転しました。六つのパネルに 484 本の観測経路、重複しない三つの増加幅、九つのしきい値の差と不確かさを示します。
