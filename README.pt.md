## Três formas de trabalhar

<a id="start-with-skill"></a>

### Início rápido · Skill de fluxo completo

Chame `$paper-spine` no chat com uma pergunta, dados ou um rascunho. Receba notas, análises, figuras e um manuscrito editável dentro do escopo combinado.

[**Baixar ZIP**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-skill-6.0.0-beta.2.zip) · ![Downloads no GitHub Releases](https://wubing2023.github.io/PaperSpine/v6/downloads-skill.svg?style=flat)

### Pesquisa especializada · Pacote de Skills

Use `$paper-spine` para todo o fluxo ou invoque uma etapa diretamente. Por exemplo, `$paper-spine-followwriting` ajuda a revisar uma seção com seus próprios resultados e artigos de referência.

[**Baixar ZIP**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-skills-pack-6.0.0-beta.2.zip) · ![Downloads no GitHub Releases](https://wubing2023.github.io/PaperSpine/v6/downloads-skills-pack.svg?style=flat)

### Ambiente de revisão · Plug-in web

Adicione o ambiente local opcional para examinar figuras, visualizar rascunhos e enviar notas de revisão no navegador. Inclui o pacote de Skills e usa `$paper-spine-web:paper-spine-web` no Codex para Windows x64.

[**Baixar ZIP**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-web-plugin-6.0.0-beta.2-windows-x64.zip) · ![Downloads no GitHub Releases](https://wubing2023.github.io/PaperSpine/v6/downloads-web-plugin.svg?style=flat)

| Skill | O que pedir |
| --- | --- |
| `$paper-spine-study` | Planeje um teste pareado com estes dados e salve os resultados por divisão. |

<a id="installation"></a>

## Instalação e atualizações

Confira o ZIP com a lista de somas de verificação. Extraia e execute o gerenciador na pasta extraída, informando o caminho do ZIP original e seu SHA-256 completo. Em seguida, abra um novo chat.

```text
python -B edition_manager.py install "<original ZIP path>" --sha256 <SHA256>
```

O gerenciador exige Python 3.12 ou posterior. O ZIP web inclui Python para Windows e exige a CLI do Codex. Instalações gerenciadas aceitam verificações automáticas, atualização manual, reversão e remoção. Os rascunhos e as tarefas locais são preservados.

[Instalar, atualizar ou remover](https://wubing2023.github.io/PaperSpine/v6/pt/install.html) · [Somas de verificação SHA-256](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/checksums.sha256) · [Versão V6](https://github.com/WUBING2023/PaperSpine/releases/tag/v6.0.0-beta.2)

## Como o PaperSpine incorpora evidências ao artigo

- **Defina o escopo pelos materiais disponíveis.** Uma pergunta pode pedir dados públicos ou uma análise nova. Resultados existentes podem ir direto para a figura, a argumentação ou a revisão. O agente mantém os arquivos e as decisões entre etapas.
- **Rastreie separadamente a escrita e a evidência.** Followwriting indica os trechos de referência que orientaram estrutura e redação. As afirmações partem das evidências do estudo. Preserve a análise, fontes das figuras e citações para revisão.
- **Mantenha a revisão no mesmo artigo.** Salve a figura selecionada e os comentários com o manuscrito editável. A revisão pode retomar as evidências, atualizar o texto e as figuras afetadas e registrar as alterações.

O estudo do LIGO mostra o processo. Siga a ordem de chegada informada no artigo até os traços alinhados e as nove verificações de pré-processamento. [Evidências e fontes do LIGO](https://wubing2023.github.io/PaperSpine/v6/pt/#gravitational-waves)

## Intensificação de ciclones atlânticos em condições iniciais comparáveis

Com o Skill independente, o PaperSpine comparou 42 temporadas de trajetórias da NOAA. Em 6.017 janelas comparáveis de 24 horas, a diferença em 30 nós foi de +0,81 ponto percentual (intervalo de 95% por bootstrap de temporadas de −1,69 a +3,43). A estimativa pontual a 25 nós mudou de sinal. Os seis painéis traçam 484 trajetórias observadas de 24 horas, separam aumentos em faixas disjuntas e mostram contraste e incerteza em nove limiares.

## Três artigos, três modos

GPT‑6.1 Sol usou as três edições do PaperSpine em cada estudo. As [nove execuções documentadas](paperspine5/core/07_发布页/v6/science/research/README.md#how-the-runs-were-conducted) incluem artigos, dados públicos, figuras originais, código reprodutível e registros de revisão.

### Duas fusões de buracos negros na escala de milissegundos

Em dois eventos públicos do LIGO, Hanford registrou o sinal 7,36 e 7,75 ms depois de Livingston. O sinal dos dois atrasos se manteve nas nove escolhas de pré-processamento.

Com magnitude reportada M ≥ 1,5 e entre 1 e 72 horas após o evento de Mw 7,1, os expoentes ajustados foram 0,55 no ComCat e 0,48 no catálogo relocalizado de Shelly.
