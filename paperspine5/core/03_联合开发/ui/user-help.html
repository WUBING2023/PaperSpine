从材料到可交付论文

这份文档说明如何打开任务、保存配置、阅读图件和审阅结果，以及如何下载和继续返修。

开始一次任务

  1. 在已安装 paper-spine Skill 的宿主对话中说明论文主题、材料目录、目标期刊和是否需要新增研究分析。
  2. 打开宿主提供的同一任务网页，在配置区保存语言、目标期刊、工作模式、输出格式和材料授权。
  3. 需要研究时，宿主会检索公开论文并将可用来源和结果写入任务；私有材料仍按授权范围处理。
  4. 如果已有任务，从“历史论文任务”打开原任务查看记录；打开不会启动 AI。复制接手指令发给当前宿主，不要新建任务代替恢复。

图件与选择

辅助模式下，页面会展示候选动机、参考论文和图件。逐项阅读图注、数据来源和参考对照后保存选择；机制图应先有完整构图，再进入组件优化。自动模式由宿主根据 Skill 选择并记录理由。

页面中的“已选择”只表示页面确实收到你的提交。它不等于宿主已完成绘图、审阅或最终接纳；这些状态会在后续阶段单独显示。

正文、审阅与返修

宿主会把研究结果、引用、图表和目标期刊格式组织成主稿，并保留可编辑源文件。独立审阅者检查当前实际稿件、数字、图文一致性和版式；发现问题后，宿主应修改产生问题的源稿或图件并重新检查。

初稿交付后，可以在任务页面提交具体意见或附件。宿主读取同一任务的反馈，保留旧版本，完成返修并生成新的论文包。

下载交付物

  1. 下载论文精简包，确认 PDF、DOCX 和必要引用文件可以打开。
  2. 下载完整工作区包，确认 LaTeX、BibTeX、图件、编辑源和说明文件齐全。
  3. 核对浏览器实际保存位置和文件版本。下载失败时，先查找已有文件，不要因此重跑论文。

中断后继续

打开原任务网页，复制接手指令给原对话或有本地文件访问权的新宿主。接手依靠同一任务的配置、选择、成果、反馈和必要笔记，不共享原 Agent 的记忆。先核对服务地址、任务 ID 和保存版本；只同步已保存数据，不同步各浏览器的未保存草稿。页面显示“待恢复”时，表示宿主尚未继续，不代表论文仍在后台运行。

网络、模型或工具中断后，先查看任务目录中已生成的文件和宿主最近输出，再决定是否安全重试。无法确认外部动作是否执行时，不重复提交。

隐私与边界

公开论文检索是 Skill 的正常能力。私有材料上传模型前，必须有明确授权；原始临床材料按本地清洗和授权范围处理。投稿、发布、付费和邮件等外部动作需要作者单独确认。
