# 本地教学材料：简单平均数与范围

这是为 PaperSpine 使用说明编写的原创、人工构造数据，不是观测、实验或临床结果。作者允许任何人复制、修改和再分发本目录，用于学习与测试；不附带真实研究或投稿主张。

`measurements.csv` 有 5 个教学值：2、4、6、8、10。算术平均数为 6，最小值 2，最大值 10。可选动机：解释平均数；或解释范围如何补充平均数。可选图：五点散点图；或五根柱图。不要把这些选项包装为科学创新。

把本目录复制到自己的材料目录，在 Web 授权只读。要求 Agent 核对五个值，写一段可复算说明和限制，再向你请求动机与图件选择。无需外部搜索或上传。另一位审核者应独立核算总和 30、数量 5、平均数 6，检查图中五个值和“人工构造”标注。

本目录另附可编辑 note.tex 和 values.svg，内容明确标为人工构造。实际核算和选择之后，Agent 可通过已有成果发布入口，按同任务授权编号和相对文件名导入，再打包和发布本地 ZIP。演练交付的是教学说明与可编辑图源，不是完整 PDF/Word 科研论文。完整 API 操作见安装包根目录 API_REFERENCE.md。
