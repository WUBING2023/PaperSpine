# PaperSpine V6

V6 brings the whole paper workflow into your agent's chat and offers the workbench as an optional download.

| Download | What it gives you |
| --- | --- |
| Full Workflow Skill | Start with a question, results, or a manuscript and call `$paper-spine` once. |
| Skills Pack | Call the full workflow or use research, Followwriting, figures, review, and delivery separately. |
| Web Plugin | Install the Skills Pack with the local workbench, for Windows x64 and Codex. |

Followwriting uses real reference papers to guide the structure and language of a draft. It can produce paragraph- or sentence-level comparisons while retaining the study's own evidence and conclusions.

The installer verifies each ZIP, updates the selected edition as a group, supports rollback and uninstall, and preserves paper and task data. The public packages use the V6 beta channel. V5 has its original downloads and update channel. Use a new V6 workbench profile when trying the beta with an existing V5 installation.

已验证三个安装形态的本地安装、整包更新、回退和卸载。Web 插件保留同一测试任务。首次公开版本为 beta，Web 入口的已验证平台是 Windows x64 Codex。旧项目可先从原本地论文文件继续使用 V6 的 Skill。
