Agent installation guide

Choose a PaperSpine V6 edition, verify its release archive, and confirm that your AI agent can find the Skill.

Plain text for agents (.txt)

Choose an edition

Full Workflow Skill skill
For working on a research question, results, or a draft in chat. Invoke $paper-spine.
Skills Pack skills-pack
The full workflow and five individually callable stages. Invoke $paper-spine or a stage such as $paper-spine-followwriting.
Web Plugin web-plugin
The Skills Pack with a local workbench. Requires Windows x64 and the Codex CLI. Invoke $paper-spine-web:paper-spine-web in a new Codex chat.

Verify and install

  1. Identify your host and its Skill directory. The edition manager defaults to the current user's Codex Skill directory and requires Python 3.12 or later. The Web Plugin archive includes Windows Python.
  2. Find the edition in the V6 manifest. Download its ZIP and compare the full SHA-256 with the manifest and published checksums.
  3. Extract the verified ZIP. From its extracted folder, run the manager with the absolute path to the original ZIP.
python -B edition_manager.py install "<absolute path to original ZIP>" --sha256 <SHA256>

For another host's Skill directory, pass --skills-root "<host Skill directory>" before install. Use the same directory for subsequent manager commands.

Confirm the installation

python -B "<manager path>" status

Use the manager path printed by the installer and the same interpreter and Skill directory. Confirm the edition and version, then open a new chat in your host and check that the Skill appears.

给 Agent 读的纯文本（.txt）

选择版本

全流程 Skill skill
从研究问题、数据、结果或草稿出发，在对话中调用 $paper-spine。
Skills 包 skills-pack
包含全流程入口和五个可独立调用的阶段。可调用 $paper-spine，也可调用 $paper-spine-followwriting 等阶段 Skill。
Web 插件包 web-plugin
在 Skills 包基础上提供本地工作台。需要 Windows x64 和 Codex CLI。在新 Codex 对话中调用 $paper-spine-web:paper-spine-web。

校验并安装

  1. 确认宿主和它的 Skill 目录。管理器默认使用当前用户的 Codex Skill 目录，需要 Python 3.12 或更新版本。Web 插件包内含 Windows Python。
  2. 在 V6 版本清单中找到所选版本的 ZIP。下载后，将完整的 SHA-256 与清单和官方校验值比对。
  3. 解压通过校验的 ZIP。在解压目录中运行管理器，将原始 ZIP 的绝对路径传给它。
python -B edition_manager.py install "<原始 ZIP 的绝对路径>" --sha256 <SHA256>

使用其他宿主目录时，在 install 前加 --skills-root "<宿主 Skill 目录>"。后续管理命令也用同一目录。

确认安装结果

python -B "<管理器路径>" status

使用安装器输出的管理器路径、相同的 Python 解释器和 Skill 目录。核对版本后，在宿主里新开一个对话，检查 Skill 是否可以调用。
