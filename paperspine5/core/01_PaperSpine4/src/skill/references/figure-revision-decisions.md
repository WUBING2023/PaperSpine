# Diagnose a figure revision before redrawing

Use when revising existing figures, especially after mixed feedback or an
unsuccessful redesign. This supplements scientific-figure-workflow.md; it does
not restart intake, demand new references for a label fix, or add approval steps.
Use the existing figure notes for the decisions below.

## Recover the baseline and name the actual problem

Resolve the accepted revision per figure from the user's choices and comments,
not modification time or a folder called latest. Acceptance of a layout does not
approve its numerical claims. A request to restore an earlier structure while
changing labels or spacing means restore that structure, then apply the local
edit. Keep both versions. Record briefly: retained source, requested change,
meaning that must survive, and new output.

Diagnose the complaint in the actual image before choosing a repair:

| Observed problem | First useful repair |
|---|---|
| Too much descriptive text | Move explanations to the caption; retain scientific labels and evidence |
| Loose or over-tall composition | Reduce uninformative gaps, align related regions, reroute connectors; preserve legible type |
| Repeated evidence | Ask what inference disappears if a region is removed; merge or relocate genuine duplicates within the authorized revision |
| Independent panels without a story | Link existing objects through shared coordinates, identities or nested scales; establish a dominant finding |
| Missing contribution | Identify the unanswered scientific question and missing evidence; distinguish authorized analysis from a drawing change |
| Too small after manuscript placement | Recompose at the intended width; do not approve a zoomed source export |

These diagnoses can coexist. Do not answer a text complaint by deleting useful
panels, or an evidence gap by adding more metric plots. Conversely, a previously
liked structure is not a reason to preserve misleading claims. Correct those
locally and explain the changed meaning.

## Make density come from relationships

For available input, output, intervention and effect readouts, inspect whether
they can form one aligned evidence object. For example, a response matrix can
share output position with the track above and intervention identity with a
marginal effect curve. Verify that row order, object IDs, coordinates and units
actually match; independent sorting can create a false visual relationship.
Do not invent missing readouts to complete this composition.

Give the evidence answering the main question enough visual weight. A colorful
atlas or sequence logo should not dominate merely because it is attractive.
Shared absolute scales may make weak responses pale: retain that information.
A separately normalized view needs an explicit label and a scientific purpose;
it cannot silently replace an absolute comparison to make effects look alike.

Use the caption-drafting/text boundary in scientific-figure-workflow.md. For paper
artwork, explanatory panel headings and duplicate subtitles belong in the caption
by default. Start that caption now if none exists; keep necessary entity names,
axes, units, keys and qualifiers on the figure. Reflow the freed title space.
Do not answer a text complaint by removing evidence or changing plotted values.

When reference adaptation appears scientifically thin, apply the panel-substitution
decision in figure-reference-mapping.md before redrawing. Separate unused available
evidence from uncomputed or unavailable evidence. Correct labels and a truthful
caveat do not make a single-gene example equivalent to a functional analysis, or
a repeated average equivalent to a new explanatory layer.

Choose highlighted examples from an explicit rule and eligible population. Name
the quantity: strongest paired improvement differs from highest absolute score;
the smallest positive improvement is not a failure. Retain selected IDs, values
and tie handling with the existing result notes or table. Reuse frozen selections
when analysis is outside scope; do not silently recompute them during restyling.

## Compact architecture without changing the computation

For geometry-only edits, read the actual method and retain its operations,
dimensions and directed connections. Check what feeds each branch, where paths
join and which operation receives the result. Adjust routing lanes, spacing and
container bounds before deleting nodes or shrinking text. Preserve separately
requested operation boxes. Inspect arrowheads, visible junctions and endpoints
in the export; a tidy source path can be occluded or appear to enter the wrong
box. Apply one arrow grammar for each relationship meaning.

Use the paper's chosen semantic palette across data and architecture where the
same roles recur, with distinct conventions for unrelated quantities. A project's
NPG or other named palette is a preference, not a journal-wide requirement.

## Design and judge at the placed size

Resolve figure width separately from body column count. Start the composition at
its intended placed width. For uniform scaling, estimate:

`placed font size = source font size × placed width / source width`

For example, 7 pt text in a 185 mm source becomes about 3.39 pt at 89.5 mm.
Recheck the actual export bounds after tight cropping, and inspect the final PDF
or Word placement because further scaling can occur there. Record the smallest
ordinary label and any required venue/user threshold in the existing QA notes.
Outlined or raster text needs visual checking; absent extractable text is not a
pass. Do not invent a universal minimum. If it cannot fit readably, recompose or
relocate supporting detail; do not silently override an explicit column choice.

Before ranking series or naming replicates, trace labels to the generating data
and transformations, including pooling, inversion, normalization and evaluation
definitions. A corrected legend does not resolve a separate comparability flaw.
For a label-only request, preserve plotted values, display inversion, scales and
geometry; describe an existing inversion accurately in the label or caption.
Do not change the sign of a track to repair its name. A distinct data/encoding
error needs its own evidenced correction, not an incidental change of values.
Keep visual preference, source fidelity and submission readability as distinct
judgments.

Compare the published exemplar, accepted study baseline and candidate in their
actual roles. Use the intended physical width and retain a readable enlarged
view for inspection. Explain the concrete improvement and remaining gap, not a
panel-count score. Historical skill trials can suggest transferable operations;
one implementation per skill does not establish a causal winner. Test a changed
decision on a realistic case before claiming that the skill's output improved.
