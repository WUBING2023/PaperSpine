# PaperSpine Scientific Figures

Identify the result or explanation the figure must convey. Open the real data, chosen existing figure and manuscript context when available. Use [scientific figure workflow](../../skill/references/scientific-figure-workflow.md) or, for a focused change, [figure revision decisions](../../skill/references/figure-revision-decisions.md). Preserve validated results and the current editable source.

Match layout and marks to the scientific comparison. When learning from a reference, look at the full figure and caption and map transferable structure to the real evidence. For data plots, show units, independent observations and meaningful uncertainty. For conceptual drawings, distinguish observations, literature-supported relationships and hypotheses. Use deterministic editable tools for data and source text. Review labels, composition and legibility in the final-size render.

Deliver the actual vector or editable source, rendered output, and caption with panel meanings, definitions and warranted interpretation. Update links or text affected by a change when the request covers them. For a meaningful candidate choice, attach the actual figures for the user's review. Use the workbench's figure surface only when the user invokes the optional workbench.

For direct use with a managed installation, see [updates](../EDITION-MANAGEMENT.md) if available. In a full run, use the orchestrator's existing check.
