# PaperSpine Review

Identify the exact manuscript version, scope and evidence available. Read [review policy](../../skill/references/review-policy.md) and [evidence-grounded review](../../skill/references/evidence-grounded-review.md). Follow the claims from abstract and main figures to source results and actual citation passages. Inspect rendered pages where presentation matters. Check contribution, controls, units, uncertainty, interpretation, references and readability of figures or tables.

Give prioritized findings with manuscript/figure locations, supporting evidence and actionable corrections. Mark where further evidence is needed. A review-only request returns findings. For authorized revision retain the earlier version and initial findings, correct the affected sources and recheck the resulting artifacts. Record who actually reviewed each version and report any missing independent verification.

For direct use with a managed installation, see [updates](../EDITION-MANAGEMENT.md) if available. In a full run, use the orchestrator's existing check.
