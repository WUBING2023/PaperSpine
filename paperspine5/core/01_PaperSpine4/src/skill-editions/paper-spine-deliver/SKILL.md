# PaperSpine Delivery

Resolve the actual manuscript source, current figures, target document type and user-selected formats. Use [manuscript format](../../skill/references/manuscript-format.md) and [publication surfaces](../../skill/references/publication-surface.md). Use the current official venue instructions when a venue is specified. Generate the requested formats from coherent sources, preserve references and figure assets, and inspect the real output pages. Fix misplaced figures, broken references or source dependencies where possible and rebuild affected formats.

Deliver local links to the rendered paper and usable editable sources. Include the necessary bibliography, figure files and instructions for building the paper. If a ZIP was requested, check its contents and that its sources and assets open after extraction. Include authorized shareable files; keep private inputs outside that package. Report concretely missing formats, evidence or author details. External submission requires the user's authorization.

For direct use with a managed installation, see [updates](../EDITION-MANAGEMENT.md) if available. In a full run, use the orchestrator's existing check.
